# Immutable skill catalogs

This directory is generated by `scripts/build_file_indexes.py`. Each JSON file is content-addressed by the SHA-256 of its exact bytes and lists every tracked file for one manifest skill with its path, blob SHA-1, size, and Git mode.

Catalogs are immutable. Never edit a catalog in place: stage skill or manifest changes, rerun the generator, and let it publish a new hash-named file. Obsolete catalogs are intentionally retained so manifests already fetched by older MCP clients remain verifiable and downloadable.

Validation contract:

- catalog body `version` is `1`;
- `skill_path` exactly matches the manifest entry `relative_path`;
- `file_count` and `total_bytes` match the listed files;
- every listed path is relative and contained;
- every non-router manifest skill has a catalog and a tracked `SKILL.md`.

CI runs `python3 scripts/build_file_indexes.py --check`, which also detects unregistered skill directories, duplicate names, invalid paths, unstaged skill content, and missing entry points.
