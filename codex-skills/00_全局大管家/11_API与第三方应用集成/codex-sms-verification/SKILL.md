# codex-sms-verification

- **项目主页**: https://github.com/virtualsms-io/codex-sms-verification

## 功能说明
这是一款强大的短信验证码穿透工具。它通过 MCP 协议，让您的 AI 智能体可以直接购买、调度并监听来自全球 145 个国家的实体 SIM 卡短信。
无论是 ChatGPT、Claude 还是自动化无头浏览器，都可以利用此技能突破绝大多数海外平台的手机注册验证防火墙，实现全自动的账号注册和验证码填槽。
