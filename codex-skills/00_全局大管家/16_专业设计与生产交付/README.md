# 16_专业设计与生产交付

本分类用于收纳以专业设计方法和生产交付闭环为核心能力的技能。

## 适用范围

- 专业设计方案、设计规范与设计系统。
- 面向制造、施工、印刷、包装或数字化生产的工程化表达。
- 工艺约束、生产文件、交付物组织与质量验收。
- 从设计定稿到可生产、可落地成果的端到端工作流。

## 分类边界

- 任务核心是通用图片、视频、演示或视觉素材创作时，优先归入现有媒体与设计资产分类。
- 任务核心是文档、代码、科研或业务流程时，优先使用对应领域分类。
- 跨领域技能按主要交付物和用户最终要完成的生产任务归类。

本目录只定义分类边界，不单独登记为可调用技能。正式集成技能时，仍需为其建立独立技能目录和根 `SKILL.md`，并在 `skills_manifest.json` 中登记。
