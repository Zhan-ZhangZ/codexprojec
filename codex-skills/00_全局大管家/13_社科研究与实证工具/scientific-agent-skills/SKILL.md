# Scientific Agent Skills

这是一个专为科学研究领域构建的巨型开源大管家 / 代理工具集，包含了超过 170+ 个针对跨学科科研的工具。

## 使用方法

当需要调用某个特定学科的专业能力（如 `scanpy`, `rdkit`, `pennylane`, `matplotlib`, `astropy`, 等等）时，你可以深入到 `skills/` 子目录中阅读对应的 `SKILL.md` 来加载能力。
