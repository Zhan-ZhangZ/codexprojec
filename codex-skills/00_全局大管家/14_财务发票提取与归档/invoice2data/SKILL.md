# 💼 invoice2data 发票提取与归档技能

## 1. 核心法则 (Golden Rules)
- **了解指令**：在执行发票解析和分类操作前，务必先使用 `view_file` 工具阅读本目录下的 `README.md` 以获取最新使用方法和指令参数。
- **不污染原文件**：进行重命名和归档操作时，应使用原文件的副本，或确保能随时回滚。
- **模板匹配优先**：尽可能使用系统内置或自定义的 YAML 模板匹配发票格式，提高解析准确率。

## 2. 轨迹驱动执行引擎 (Execution Trajectory)
1. **输入阶段 (Initialization)**
   - 确定用户给定的发票所在目录或文件。
   - 确定目标归档路径及重命名格式。
2. **提取阶段 (Extraction)**
   - 调用 `invoice2data` 命令扫描目标 PDF/图片发票文件。
   - 输出结构化的 JSON 或 CSV 数据结果。
3. **归档阶段 (Archiving)**
   - 根据解析出来的结果（如提取的供应商、日期、总金额等），自动将发票重命名，并移动到按月或按供应商分类的归档文件夹中。
4. **输出验证 (Verification)**
   - 检查归档目录的生成是否符合预期。
   - 生成数据提取简要报告。

## 3. 异常处理模式
- **依赖缺失**：如果系统中未安装 `invoice2data` 工具，应先使用终端命令进行安装（`pip install invoice2data`）。
- **解析失败**：若无匹配模板导致解析为空，应提示用户可能需要针对特定发票补充 YAML 模板，或改用大模型直接抽取。
