# 💼 EasyAccounts 智能记账与财务管家技能

## 1. 核心法则 (Golden Rules)
- **了解指令**：在尝试部署或调用此系统前，请使用 `view_file` 阅读项目根目录下的 `README.md`，了解其基于 Docker 的部署方式和配置要求。
- **AI 赋能**：此项目最大的特色是内置 AI 助手（基于自然语言解析账单）。在作为 Agent 工具调用时，应重点利用其自然语言接口，将 unstructured 文本转化为结构化账单流水。
- **无缝衔接**：在完成 `invoice2data` 或 `Invoice_LLM` 的发票提取后，可将提取的金额、日期和消费说明作为输入，通过调用此系统的接口完成自动平账。

## 2. 轨迹驱动执行引擎 (Execution Trajectory)
1. **环境准备 (Initialization)**
   - 检查并验证当前环境是否可以访问配置好的 EasyAccounts 数据库或 API。
   - 确保账本系统处于正常服务状态。
2. **记录消费 (Transaction Entry)**
   - 接收用户的自然语言输入或发票解析模块传来的结构化数据。
   - 调用系统接口，录入金额、时间、消费类型、账户（如微信、支付宝、银行卡）。
3. **数据查询 (Query & Report)**
   - 可通过自然语言向其 AI 助手提问，例如：“本月餐饮支出多少？”、“列出上周打车费用”。
   - 将系统返回的月度/周度统计报表或图表数据汇总呈现给用户。
4. **输出验证 (Verification)**
   - 确保记录添加成功，账面余额与实际支出逻辑吻合。

## 3. 异常处理模式
- **部署失败**：如果是第一次运行，提示用户通过 `docker-compose` 启动服务，并正确配置数据库环境变量。
- **API 未响应**：如果系统后端未能响应请求，提示用户检查网络连接及后台进程状态。
