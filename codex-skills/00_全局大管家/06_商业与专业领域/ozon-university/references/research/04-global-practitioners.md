# 非中文公开 Ozon 实践者 / 机构流派调研

> 调研截止：2026-07-22（Asia/Shanghai）  
> 范围：俄语及其他非中文公开资料；优先本人/机构自有博客、公开课、Ozon 官方卖家访谈。  
> 用途：为公开主题 Skill `ozon-university` 提供“实践观点层”，不得替代 Ozon 当前合同、帮助中心和官方费率。  
> 结论：可验证的海外 Ozon 个人 KOL 证据明显弱于机构内容。第一版宜采用 **SellerCenter（案例审计派）+ Seller24（经营系统派）+ MPSTATS Academy（数据工具派）+ Кирилл Лазарев（跨平台独立卖家观察）+ Ozon 卖家访谈（小卖家原声样本）**，而不是塑造单一“海外大神”。

## 1. 证据口径与限制

- 只收录作者本人发布、机构自有站点、Ozon 官方对卖家的直接访谈；排除匿名聚合、课程搬运和无原始链接的二手转述。
- **事实**：页面可直接验证的身份、日期、案例过程或平台功能描述。案例中的营收、利润和提升幅度仍是发布者自报事实，未经过独立审计。
- **本人/机构观点**：作者明确提出的判断、阈值或方法，只代表其样本。
- **研究者推断**：根据同一来源多篇内容反复出现的步骤所做归纳，不是作者原话。
- 可信度分为：**高**（官方规则或可直接验证的原始访谈）；**中**（署名实践案例但经营数据不可独立审计）；**低**（工具商对自身产品、收益或效果的宣传）。
- 平台广告产品、佣金、仓配规则和后台入口更新很快。本文保留的是决策框架；任何具体按钮、阈值、费率在回答实习生前都必须查询当前官方资料。
- 俄语生态中，许多“案例”同时承担获客功能。若来源结尾销售代运营、审计或数据工具，Skill 必须提示商业利益冲突。

## 3. 流派画像

### 3.1 Павел Сабуров / SellerCenter：先审计，再把增长当成全系统问题

**可直接验证（中等可信）**

- Павел Сабуров 在 2024-12-05 的署名长文中自称 SellerCenter 创始人，并公开 BlackMirror 家具品牌从调研、建店到经营的 Ozon 案例。[G01]
- 案例先分析需求、竞争集中度和季节性，再决定主推梳妆台，而不是把客户所有商品一起上架；随后完成图片、SEO、卡片和内外部广告准备。[G01]
- 团队每周记录动作和 Ozon 指标，用时间线回查销量突变；运营职责同时包含商品、价格、订单、促销、竞品和广告，不把广告单独看待。[G01]
- 大件镜面家具的包装与配送每件约增加 3,000 卢布，案例把这部分计入终端价格；涨价 10% 后销量下降，但收入大致稳定。[G01]

**重复框架（本人观点 + 研究者归纳，中等可信）**

1. **选品：先做需求、竞争、季节和供给能力审计**。是否进入 Ozon、主推哪个 SKU，先由数据和生产能力决定。[G01]
2. **内容：卡片是广告前的地基**。竞品图片、描述、SEO 与关键词一起研究；高价商品可用内容和质量，而不是最低价，建立差异。[G01]
3. **定价：把制造、包装、运输和广告一起算**。成交量下降不必然是坏事；若价格上调后收入/利润稳定，低价并非唯一解。[G01]
4. **广告：内外部广告要服从卡片和产能**。案例最终出现“停止广告，产能跟不上”的情况，说明供给不足时继续买流量会放大履约风险。[G01]
5. **履约：先理解生产周期和易损品包装**。大件、易碎、高客单品的物流约束会反向决定价格、库存和放量节奏。[G01]

**适用条件**

- 更适合制造商、高客单、大件/易碎商品，以及有明确生产周期的品牌。
- 不宜把案例中的营收增长外推到低价快消、跨境直邮或无自有产能卖家。

**争议与边界**

- “完整代运营团队 + 一个月准备”对实习生有启发，但对小卖家成本过高。
- 文中经营结果来自服务商自报；应学习流程，不复述为可保证的收益。

### 3.2 Seller24：分组—周度漏斗—季节轮换—再放量

**可直接验证（中等可信）**

- 2024-05 的牛仔服新店案例先做审计和 SKU 级媒体计划，计划中含预计营业额、营销预算、日/周/月预算和 CTR；机构明确提示广告初期 ДРР（广告费用占销售额）可能偏高。[G02]
- 同一案例把缺货、滞销、价格/促销分别映射到库存预测、ABC 分析和单位经济模型，主张先用免费流量，再连接付费推广。[G02]
- 2024-12 的宠物用品案例把 FBS-only、缺货、卡片、品牌和广告作为同一问题处理；转 FBO、改图片/SEO、稳定补货后，才持续测试广告。[G03]
- 2025-12 的工具案例由 менеджер Павел Мясников 和 маркетолог Олег Кутовенко 署名参与。团队按品类拆广告组，做 ABC 分析，每周追踪 CTR、CR、ДРР；季节切换时移除夏季 SKU，并停掉 ДРР 高于 25% 的商品。[G04]
- 该案例给出的优化顺序是 **CTR → 加购 → 订单 → ДРР**，并明确“先结构、再优化、后规模化”。[G04]

**重复框架（机构方法，中等可信）**

1. **选品/组合：ABC 不是装饰，而是预算和库存分配器**。先找商品火车头；新店数据不足时不要机械做 ABC，可先小范围积累样本。[G02][G03][G04]
2. **内容：低 CTR/低加购先查视觉、短 USP、SEO 和预期匹配**，不要只抬竞价。[G03][G04]
3. **定价：任何促销先过单位经济**。把佣金、物流、广告和目标利润纳入价格模拟；“参加活动后会怎样”是情景计算，而不是跟随平台推荐价。[G02]
4. **广告：按品类/用途/SKU 分组，周度看 CTR、CR、ДРР，再逐步调价和过滤 SKU**；基础漏斗可解释后才扩大预算。[G04]
5. **履约：库存可用性是广告开关**。按 FBO/FBS、地域销售、售出率和预测补货；货不够时不要继续放量。[G02][G03]
6. **变化管理：广告策略有保质期**。Seller24 明确指出一年内 Ozon 广告模型、最低竞价和预算规则变化，历史打法不能永久固化。[G03]

**适用条件**

- 适合已有多个 SKU、能获得周度漏斗数据、正在从混乱投放转向结构化经营的店铺。
- 新店、订单太少时，ABC 和 CR 的噪声很大，应先积累样本，不要过早淘汰商品。

**争议与边界**

- “ДРР > 25% 就停”只适用于该工具品类案例，不是全店通用阈值。新品冷启动、不同毛利和复购品类可能容忍更高短期获客成本。[G04]
- Seller24 同时销售代运营和分析工具；所有“提升 X 倍”只能标为机构案例主张，不能成为 Skill 的承诺。

### 3.3 MPSTATS Academy / Consulting：外部数据辅助的诊断派

**可直接验证（中到低可信）**

- MPSTATS 官网公开课目录包含“WB 和 Ozon 商品卡显微镜”，公开说明会检查卡片、物流、评论、库存和季节性；另有视觉/CTR、外部广告和上 Top 的课程。[G05]
- MPSTATS 自有插件页宣称可查看类目销售/收入、价格变化、退货、仓库与配送时间、关键词、广告位置/竞价、CPO、加购和订单转化。[G06]
- Seller24 与 Кирилл Лазарев 的公开案例都把 MPSTATS 用于竞品、价格、需求或地域分析，但这仍不是对数据准确性的独立验证。[G03][G07][G08]

**重复框架（研究者推断，中等可信）**

1. **先定位漏斗环节**：曝光/位置 → 点击 CTR → 加购 → 订单 → ДРР/CPO → 退货与利润。[G05][G06]
2. **选品先看趋势与竞争结构，再小批量验证**；外部估算提供假设，店铺真实成交负责验证。[G05][G06]
3. **地域库存与配送时间影响转化**，库存分析不能只看全国总量。[G06]
4. **广告词/商品组要看实际订单，而非只看曝光和排名**。[G06]

**适用条件**

- 适合已经有多个 SKU，或需要快速做竞品/关键词假设的团队。
- 对零订单新店，外部数据只能帮助列假设，不能替代真实小批量测试。

**争议与边界**

- 市场销量、竞争对手销量、退货等外部估算未见本轮可访问材料中的独立误差审计。Skill 应说“用来提出假设”，不能说“数据就是真实销量”。
- 课程同时覆盖 Wildberries 和 Ozon，任何广告按钮、指标定义和物流结论必须回到 Ozon 当前文档确认。

### 3.4 Кирилл Лазарев：利润优先、缩减 SKU、小批量测试（观察名单）

**可直接验证（中等偏低可信）**

- 其 Sostav 本人博客在 2025-07 至 2025-12 连续发布库存、选品、价格、折扣、退货、内容和数据经营文章；其中一篇明确提到商品曾分布在 Wildberries、Ozon 等平台。[G07][G08][G09][G10]
- 2025-08-15 文章自报从 128 个 SKU 缩到 82 个，先做 ABC，再对新品用 100—200 件小批量测试；定价看价格区间而不是只追最低价。[G08]
- 2025-09-09 文章提出促销必须先设最低利润线，并把促销商品与互补品组合；其“最低 12% 毛利”是该经营者内部规则，不是行业标准。[G09]
- 2025-08-25 文章把退货按 SKU/原因记录，并用真实参数图片、视频、详情和仓库质检减少“与预期不符”及运输损伤。[G10]

**重复框架（本人观点，中等偏低可信）**

1. **选品：广度不等于利润**。按利润和周转淘汰长期低效 SKU；新品小批量测试，避免一次压货。[G08]
2. **内容：卡片必须降低预期差**。真实尺寸、材质、重量、场景图和视频同时服务于转化与退货控制。[G10]
3. **定价：看净利润而不是漂亮 GMV**。价格战可能提高订单但伤害利润；折扣前先模拟佣金和成本。[G08][G09]
4. **履约：退货是产品/内容/质检信号**。按 SKU 记录原因，再决定改卡片、改包装、换供应商或退场。[G10]
5. **广告：预算应集中在能证明利润与周转的 SKU**。此点是从其 ABC、促销和利润规则推断，文章未提供完整 Ozon 广告实操。[G08][G09]

**适用条件**

- 适合已有经营数据、SKU 膨胀、现金被库存占用的多平台卖家。
- 不适合作为 Ozon 专属后台操作教程。

**争议与边界**

- 多篇文章数字非常具体，但店铺、账表和数据口径不可独立核验；不得把 12% 毛利、100—200 件测试量、3 个月淘汰期写成统一标准。
- 文章频繁提及 MPSTATS，可能存在工具推广关系；本轮未确认商业合作性质。

### 3.5 Ozon 官方卖家访谈：小店验证与品类适配流

**可直接验证（高：访谈存在；中：经营数据为受访者自报）**

- 艺术家 Дарья Теплова 在 2025-07-29 的 Ozon 访谈中说，她先在社交媒体看作品反馈，再把有反响的作品制成海报；以 FBS 起步，并根据订单地域安排供货。[G11]
- 她明确表示，利基海报的付费推广尚未找到合算策略；建议新品小批量测试、完整核算到“每一戈比”，并警告新手不要借大额贷款赌短期成功。[G11]
- GT Dress 创始人 Далия Гайнанова 的 2024-09-23 访谈显示，其产品源于明确未满足需求；Ozon 当时甚至没有对应的适应性服装类目，品牌推动了分类建立。[G12]

**重复框架（跨两个访谈的研究者归纳，中等可信）**

1. **选品从具体用户问题出发**，而不是只复制排行榜热品。[G11][G12]
2. **低资金/利基品类先用小批量和 FBS 验证**，确认需求后再扩大库存。[G11]
3. **内容要忠实呈现产品**。对颜色、尺寸、使用场景容易产生误差的商品，减少预期差比夸张卖点更重要。[G11]
4. **广告不是所有品类的必选项**。利基、非高频商品可能难以承受广泛付费流量，应先看自然订单与单位经济。[G11]

**适用条件**

- 适合原创产品、长尾利基、手工/小批量生产者和试水阶段的新卖家。
- 不应外推到标准化快消、强搜索需求或成熟品牌。

**争议与边界**

- Ozon 官方访谈存在成功者选择偏差，且会突出平台带来的帮助；它们适合作为“真实问题样本”，不适合证明平均收益。

## 4. 跨流派共识：可转为问答助手的默认诊断顺序

下列是多个来源重复出现的**研究者综合**，不是某一位作者的逐字结论：

1. **先算单位经济与供给边界**：采购/制造、佣金、仓储、配送、退货、包装、广告、促销后利润；同时确认库存和产能是否承受增长。[G01][G02][G03][G08][G09]
2. **再判断选品与季节**：需求、竞争集中度、区域、季节、周转；新品先小批量验证，多 SKU 店铺用 ABC 分层。[G01][G02][G04][G08][G11]
3. **卡片先于放量**：类目、属性、SEO、主图、短 USP、场景/尺寸/材质、视频；目标既是提高 CTR/CR，也是减少退货。[G01][G03][G04][G10]
4. **广告按漏斗诊断**：曝光/位置 → CTR → 加购 → CR → 订单 → ДРР/CPO → 净利润。CTR 差先改首图/相关性；加购后不下单再查价格、配送、评价与预期；不要只提竞价。[G02][G04][G05]
5. **履约决定能否扩大广告**：库存地域、FBO/FBS、配送时间、易损包装、退货原因和生产周期应与投放同步。[G01][G03][G05][G10][G11]
6. **按周记录动作与指标**：一次只改少量变量，保留改价、换图、调广告、补货和促销的时间线，才能解释波动。[G01][G04]

建议 Skill 对实习生采用以下回答模板：

```text
问题属于：选品 / 内容 / 定价 / 广告 / 履约 / 平台规则
先要数据：SKU、时间窗、曝光、CTR、加购、订单、广告花费、ДРР/CPO、售价、全成本、库存地域、配送时效、退货原因
先做：一个最小且可逆的动作
再看：约定时间窗内哪两个指标变化
来源性质：官方事实 / 实践者观点 / 研究者推断
升级条件：规则不明、可能亏损、合规/账户风险、数据不足
```

## 5. 关键分歧：答案不得伪装成唯一正确

| 问题 | 路线 A | 路线 B | Skill 应如何回答 |
|---|---|---|---|
| 热品还是利基 | Seller24/数据派：通过类目和季节找到有规模的商品火车头 | Ozon 小卖家访谈/Лазарев：从未满足需求或稳定常青品切入，避免盲追热品 | 先问资金、供应链、品类专业性和试错成本；两条都可行 |
