# 来源与时效规则

## 来源等级

按以下优先级使用信息：

1. **Ozon 官方一手来源**：Seller Help、Global Seller、官方公告、官方培训和后台实际提示。
2. **公开实践者一手内容**：作者本人发布的视频、直播回放、文章或演讲。
3. **可信二手来源**：能够指向原始材料的权威媒体或服务机构说明。
4. **推断**：根据用户数据和已知机制形成的假设，必须明确标为“待验证”。

不要把搜索摘要、聚合转载、匿名截图或无法定位原文的说法当作规则。不要使用知乎、微信公众号、百度百科或百度知道作为证据来源。

## 时效处理

以下内容默认具有高时效风险：

- 佣金、费率、罚款和最低预算；
- 类目限制、禁限售要求和认证要求；
- 物流方式、覆盖区域、时效和计费；
- 广告产品、后台入口和投放规则；
- 入驻、结算、退货、取消和争议处理规则；
- 任何包含“现在、最新、目前、最近”的问题。

回答这类问题前，优先访问 Ozon 官方页面或后台。记录核验日期。无法联网或没有官方证据时，不给出精确数字，改为说明核验路径。

## 回答前核验门

1. 先确认卖家注册国家、销售市场、类目和履约方案；物流/订单问题再确认承运商与状态，广告问题再确认当前后台工具名。
2. 费率、金额、百分比、天数、重量、路线、承运商、广告资格、活动规则、退货责任、处罚阈值、搜索权重和评级公式都要当场核验。
3. 先比较来源是否适用于同一国家、主体、履约、类目和工具，再比较发布日期。更晚但面向其他市场的公告不会自动覆盖当前账号。
4. 费用与责任优先看适用合同/Offer，账号功能和实际输入项优先看当前后台；仍冲突时并列披露并升级官方支持。

Ozon URL 可能因国家参数、语言、缓存和登录状态显示不同内容。其他国家参数的页面只能证明机制存在，不能证明中国卖家的当前费率或路线。

## 引用格式

在答案末尾用简短清单标注：

- `[官方事实｜核验 YYYY-MM-DD] 页面标题 — URL`
- `[公开实践者观点｜发布 YYYY-MM-DD] 作者：内容标题 — URL`
- `[待验证推断] 推断依据与验证动作`

## 冲突处理

- 官方规则与实践者经验冲突：以当前官方规则为约束，保留经验作为情境建议。
- 两位实践者冲突：说明各自适用的店铺阶段、品类、预算和履约能力，不替用户强行选边。
- 官方页面之间冲突：优先更具体、更新更晚、与用户站点和业务模式更匹配的页面；仍无法判断时停止并建议咨询官方支持。

## 内容权利与隐私

只做必要的摘要和框架提炼，不大段复制第三方内容。不暴露用户账号、订单、买家信息、联系方式、密钥、店铺经营数据或公司内部规则。
