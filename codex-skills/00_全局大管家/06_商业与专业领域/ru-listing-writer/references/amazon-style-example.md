# Amazon-style description pattern

Read this reference only when drafting the description. It demonstrates structure and image-to-bullet order, not reusable product facts or wording.

## Structural pattern

For an ordered image set:

- `主图`: identifies the product and may preview several benefits;
- `图2`: develops verified selling point A;
- `图3`: develops verified selling point B;
- `图4`: develops verified selling point C or a use case.

The description should normally follow A, B, C. A main-image point comes first only when it is distinct and substantive. If A and B are duplicates, merge them at A's earliest position and note that merge in the evidence summary.

Use this bullet shape:

`• практический результат — подтвержденная характеристика объясняется через понятную пользу для покупателя, без неподтвержденной гарантии или измеримого обещания.`

Each bullet should:

- begin with exactly `• `;
- lead with a concrete buyer outcome;
- connect that outcome to facts visible or stated in the seller's images;
- integrate relevant quantity, dimensions, material, compatibility, use, or instructions;
- remain focused on one benefit cluster;
- apply the marketplace rule: WB descriptions use lowercase Cyrillic throughout, while OZON uses normal Russian capitalization;
- use cautious wording for performance that lacks independent test evidence.

Do not reuse claims from examples. Never add percentages, `premium`, guaranteed durability, complete protection, universal compatibility, certifications, or measured performance unless the seller's evidence supports them.
