# digikey_mcp — 电气与智能化设计 MCP 服务

- **项目主页**: https://github.com/bengineer19/digikey_mcp

## 功能说明

DigiKey 官方产品数据库查询 MCP。支持根据关键词或零件编号检索 DigiKey 实时元器件库存、多量阶价格、替代型号推荐及元器件包装与物理参数。
