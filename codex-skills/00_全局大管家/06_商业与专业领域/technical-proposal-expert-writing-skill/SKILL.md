# 软件工程常用文档辅助技能

请在执行前先使用 `view_file` 阅读本项目自带的 `README.md`，以获取完整的命令参数和模版知识。

## 核心法则 (Golden Rules)
- 严格遵循软件工程文档规范进行内容生成。
- 保证技术文档的完整性和逻辑连贯性，优先采纳规范化术语。

## 轨迹驱动执行引擎 (Execution Trajectory)
1. **需求理解阶段**：分析用户要求生成的具体文档类型（如概要设计、详细设计等）。
2. **检索参照阶段**：参考对应目录下的模板与示例（如“设计阶段”、“测试阶段”等）。
3. **内容生成阶段**：根据文档目的，生成严谨的技术标书或工程文档。
4. **校验润色阶段**：审核生成的文档是否满足软件工程标准，格式是否达标。

## 异常处理模式
- 若用户要求的文档类型不在已知模板内，请主动提醒用户提供额外的要求，或通过检索建议相近类型的工程文档模板。
