# TradingAgents

- **项目主页**: https://github.com/TauricResearch/TradingAgents

## 功能说明
顶级的 AI 金融投研多智能体协作框架。将投资决策流程拆解为基本面分析、情绪分析、新闻监测、技术指标分析、研究员、交易员以及风控管理等多 Agent 角色，可深度演练和定制完整的 AI 投研团队。
