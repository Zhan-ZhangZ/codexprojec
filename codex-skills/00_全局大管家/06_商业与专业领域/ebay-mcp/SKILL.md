# ebay-mcp — 跨境电商与店铺管理 MCP 服务

- **项目主页**: https://github.com/YosefHayim/ebay-mcp

## 功能说明

eBay 跨境电商店铺自动化运营 MCP。对接 eBay Sell APIs，提供包含产品在线刊登、订单履行与面单打印、营销折扣活动设置及店铺销量分析在内的 300 多个交互工具。
