# yuandian-mcp-server — 中国法律相关 MCP 服务与智能体技能

- **项目主页**: https://github.com/yuandian-ailaw/yuandian-mcp-server

## 功能说明

元典开放平台 MCP Server 是面向法律与企业数据场景的标准化 MCP 接入服务，支持法律法规查询、案例文书检索和企业信息获取，帮助智能体快速接入权威法律数据能力。
