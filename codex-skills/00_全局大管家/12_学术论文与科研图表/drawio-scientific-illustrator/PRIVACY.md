# Privacy

## English

Draw.io Scientific Illustrator runs locally. Its live MCP server binds only to `127.0.0.1` and controls the draw.io desktop application's own graph API through a local debugging channel. The plugin does not provide telemetry, analytics, account collection, or a hosted service.

Reference images and diagrams remain on the user's machine unless the user separately asks Codex or another tool to upload or share them. Users should review their own Codex and model-provider privacy settings because those services are outside this plugin.

## 中文

Draw.io Scientific Illustrator 在本机运行。实时 MCP 服务器仅绑定到 `127.0.0.1`，并通过本地调试通道调用 draw.io 桌面应用自身的图模型 API。本插件不包含遥测、统计分析、账户收集或托管服务。

参考图片和图表默认保留在用户电脑中，除非用户另外要求 Codex 或其他工具上传或分享。Codex 与模型服务商不属于本插件，用户应另行检查其隐私设置。
