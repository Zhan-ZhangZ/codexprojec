# LLM-based-Multi-Agent-System-Architecture-Design-and-Project-Code-Practice

这是陈光剑编著的《LLM-based Multi-Agent 系统架构设计与项目代码实践》书目快照，包含前言、理论、架构、Agent 实现、协作机制、评估和实践等章节。

## 何时使用

- 用户要查阅这本书的章节、概念或作者观点。
- 需要以书中框架分析多 Agent 系统的分工、通信、记忆、评估或落地。
- 需要把书中建议与目标项目的实际约束结合，而不是把书中的示例当成可运行代码。

## 使用方式

1. 先读 `README.md` 的目录，定位最相关章节。
2. 读取对应章节的 Markdown 文件。优先引用原文中的章节名与结论。
3. 这本书是知识资料，不包含可安装的产品。需要实现时，先把书中的概念转成当前项目的设计决策，再检查真实代码、依赖和测试。
4. 回答时区分“书中观点”和“针对当前项目的推断”，不要声称章节中的示例已经在本地运行。
