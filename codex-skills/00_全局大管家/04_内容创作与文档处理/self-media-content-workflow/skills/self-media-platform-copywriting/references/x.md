# X 平台

## 适合内容

观点、实时判断、行业讨论、实操经验、资源筛选、故事和公开建造记录。

## 产物

- 短帖、长帖或线程三选一。
- 最多两条脱离主内容也能成立的短观点。
- 长文按需要提供封面和正文配图。
- 一个主要链接或行动。

## 写法

- 第一屏直接给结果、冲突、反常识或具体场景。
- 用鲜明判断和第一人称承担立场。
- 线程每条承担独立信息任务，避免把长文随意切段。
- 代码、数据和截图优先承担证明任务。
- 不堆标签，不用多个行动分散注意力。

## 检查

- 第一屏脱离后文是否成立。
- 每条线程是否有推进。
- 链接和合作关系是否清楚。
- 当前字符和媒体限制是否已核验。
