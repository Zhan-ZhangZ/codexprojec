# 指标定义与比较规则

## 原始字段

| 字段 | 说明 |
|---|---|
| 曝光 | 内容被展示的次数 |
| 阅读或播放 | 用户实际打开或播放的次数 |
| 完播 | 平台提供的完成率或完成次数 |
| 点赞 | 轻量正反馈 |
| 评论 | 公开讨论和问题 |
| 收藏 | 延迟使用价值 |
| 分享 | 主动传播 |
| 新关注 | 内容带来的新增关注，平台未提供时留空 |
| 转化 | 注册、咨询、购买等明确目标行为 |
| 收入 | 可归因收入，无法归因时留空 |
| 制作分钟 | 从研究到交付的人工投入 |

## 派生指标

- 每千浏览新关注 = 新关注 ÷ 阅读或播放 × 1000。
- 深度互动率 = 评论、收藏、分享之和 ÷ 阅读或播放。
- 点击率 = 阅读或播放 ÷ 曝光，仅在字段定义一致时计算。
- 转化率 = 转化 ÷ 指定分母。必须注明分母。
- 单个有效成品时间 = 制作分钟 ÷ 达到成功标准的成品数。

分母为 0 或字段缺失时留空，不填 0。

## 比较规则

- 只比较同平台、同内容类型和相近观察窗口。
- 优先使用中位数和 P75，避免平均数被爆款拉高。
- 跨平台只比较标准化指标，不比较原始播放量。
- 商单和自然内容分开。
- 至少 3 个同类样本才描述初步模式，至少 4 个样本才考虑调整长期比例。
- 热点、投流、账号体量和平台推荐可能造成混杂，无法排除时标记不确定。
