# 数字人视频制作规范

本规范是 `self-media-short-video` 的可选制片分支。它描述输入、人工确认、生成、合成、验收和降级，不绑定某一家数字人或视频工具。

## 进入条件

只有同时满足以下条件，才能进入数字人制片模式：

- 用户明确选择数字人视频，而不是只要脚本或分镜。
- 已确认母题、口播稿、目标平台、目标时长和主要行动。
- 用户是头像与声音对应的本人，或持有可核验的明确授权。
- 用户已了解所选平台当前关于存储、模型改进、第三方处理、删除和退出机制的条款。
- 用户本人已在 Topview 或所选数字人平台中手动上传、创建和选定数字人及声音，并明确确认已就绪。
- 已确定画幅、画面风格、人物窗口位置、字幕形式和是否需要 AI/数字人披露。

如果缺少上述任一项，回到方案模式，列出缺口，不猜测用户授权或平台规则。

## 制片流程

1. **权利与数据处理预检**：确认用户是本人或持有明确授权，并已了解所选平台当前的存储、模型改进、第三方处理、删除和退出机制。只记录确认状态，不记录敏感原始素材或平台私有标识。
2. **用户手动上传**：由用户本人登录 Topview 或所选平台，手动上传、创建并选定数字人和声音。本 Skill 不调用上传凭证、文件上传或声音克隆接口代替这一步。完成后由用户确认“数字人和声音已就绪”。
3. **口播准备**：将最终口播稿作为唯一台词源。建立本任务的专名、英文缩写和数字发音词表；修改发音必须回写台词或词表，不能只在成片后凭感觉修音。
4. **生成数字人片段**：使用运行时已发现的数字人生成能力和用户已选定的现有平台素材，生成与台词同步的讲解片段。付费生成前遵守工具的费用确认规则。优先自然眨眼、轻微点头、符合语义的手势和表情，避免循环僵硬动作。
5. **合成画面解析**：主画面负责证据、流程、对比或界面演示；人物窗口只承担陪伴和强调，不遮挡关键信息。竖屏画面中要保留完整脸部、头部和足够的肩部或上半身，避免最终只剩一个头像。窗口默认优先使用圆角矩形；只有在完整上半身仍清晰可见时才使用圆形或椭圆形。
6. **添加字幕**：字幕放在正文视觉层，使用自然断句和适合手机阅读的行宽；不添加任何额外角标、栏目标签或说明性标签。字幕必须与最终音频逐句一致，专名和数字按词表统一。
7. **输出与复核**：按平台目标导出竖屏成片。抖音和小红书通常优先使用 9:16；精确分辨率、时长上限、AI 标识和商业披露以发布时平台界面或官方规则为准。导出后检查画面、音频、字幕、人物裁切和移动端可读性。

## 人工确认点

- **权利与数据处理确认**：头像、肖像、声音和第三方素材可以用于本次生成及发布，并已了解所选平台当前的数据处理条款。
- **平台素材就绪确认**：用户本人已在平台中完成上传、创建和选择；本 Skill 不代传敏感原始素材。
- **风格与布局确认**：画面风格、人物窗口形状/位置、字幕样式和是否保留 BGM。
- **终稿预览确认**：口播完整、人物自然、字幕无错、画面解析与文案一致、人物窗口没有遮挡或只剩头像。
- **发布授权**：终稿确认不等于发布授权；创建草稿或执行平台外部写操作仍需单独授权。

## 交付物

- 数字人生成片段。
- 主画面与人物窗口的画面映射或合成工程说明。
- 最终竖屏视频，以及可选的字幕文件或字幕文本。
- 封面标题、封面画面、发布标题、正文、话题、BGM 和商业/AI 披露字段。
- 肖像与声音权利确认、平台素材就绪状态、发音词表、技术规格和质量复核记录。

交付包不得包含原始头像、录音及其本机路径、临时上传/下载链接、对象存储键、文件 ID、数字人 ID、声音 ID 或可用于重新获取敏感素材的私有标识。
数字人生成片段和最终成片保存在用户内容目录或用户指定的交付目录，不写入公开的 Skill 源码仓库。

## 降级方案

- 用户未完成平台手动上传和选择：保持 `AWAITING_USER`，不尝试代传。
- 没有可用数字人生成能力：交付可手动使用的台词、头像要求、画面解析分镜、字幕稿和发布包。
- 只能生成数字人片段，不能合成画面：交付数字人片段、画面映射和字幕文件，明确未完成最终合成。
- 无法确认平台规则：不猜测标识或时长，标记待用户在发布界面确认。
- 口播不完整或音画不同步：状态保持在质量审校，不进入终稿确认。

## 最低验收标准

- 口播完整，时长与脚本、分镜一致。
- 人物脸部、头部和窗口内计划展示的上半身没有被裁切；表情和手势不出现明显循环或僵硬。
- 字幕与音频一致，没有额外角标、栏目标签、错别字、乱码或遮挡。
- 主画面承担信息任务，人物窗口不遮挡证据和关键文字。
- 原始头像、录音及其本机路径、临时链接和平台私有标识未写入任务卡、内容注册表、交付包或仓库；交付物的索引路径不在此列。
- 目标平台移动端预览可读，画幅、音量、封面和披露字段已记录。
