# AI 配图比例不对，先保住完整文字

做知识卡时，提示词要求 3:4，返回图却可能是正方形。直接居中裁切会丢掉左右边缘；如果标题或条件说明靠近边缘，尺寸合格了，内容却不完整。

本项目的生图脚本现在默认保留完整返回图。`aspect` 继续传给生图端点，但端点返回比例不符时，只提示偏差，不自动裁切。

## 怎样用

提示词文件可写：

```markdown
---
aspect: "3:4"
fit: preserve
---
在卡片中完整呈现目标、材料和验收条件，边缘留白。
```

在已配置的项目根目录运行：

```bash
python skills/aws-wechat-article-images/scripts/image_create.py generate card.md -o card.png
```

`preserve` 为默认值，省略也一样。单张和批量生成均支持 `--fit preserve`，命令行参数优先于提示词文件。

如果已经检查构图、确认边缘可以舍弃，`--fit crop` 或 `fit: crop` 可显式恢复旧版居中裁切。生成命令会调用已配置的图片服务，可能计费；它不是对本地旧图进行无费用转换的命令。不要为了测试参数重复生成。

## 这次验证了什么

复用一张已有的 1024×1024 知识卡，离线调用处理函数、目标设为 3:4：

|处理|输出|观察|
|---|---|---|
|默认保留|1024×1024|输出与输入 SHA256 一致|
|显式裁切|768×1024|左右各去掉 128 像素|

这次验证没有调用生图 API。另有单张/批量命令回归测试，用模拟 API 返回图核对保存结果和调用次数。

## 发布前仍要看

- 字是否原本就缺失、错误或重复？保留模式不能修复模型已经画错的文字。
- 平台位置是否接受这个比例？保留内容不等于满足封面规格。
- 缩小到手机观看尺寸，正文、条件和来源是否可读？

如果平台必须使用固定画幅，应调整构图或安排留白，并检查平台预览。不要把“尺寸符合”当成“内容完整”。

这是 AI Work Skills 开源项目自身配图流程的修正，并不代表任何平台新增了尺寸规则。
