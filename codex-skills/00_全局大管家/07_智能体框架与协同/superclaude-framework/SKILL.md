# SuperClaude Framework

- **项目主页**: https://github.com/SuperClaude-Org/SuperClaude_Framework

## 功能说明
给 Codex 增加一套常用指令菜单。你可以用更简单的命令，让它做分析、修 bug、写代码、优化项目、生成文档等任务。
