# lottie

- **项目主页**: https://github.com/diffusionstudio/lottie

## 功能说明
生成生产级 Lottie 动画。可以将文本提示语或设计需求直接转换为可交互、矢量无损的 Lottie 动效动画，适用于网页、App UI 交互及动态多媒体设计。
