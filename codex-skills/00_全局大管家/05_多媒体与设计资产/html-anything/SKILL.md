# html-anything

- **项目主页**: https://github.com/nexu-io/html-anything

## 功能说明
把 Markdown、文案、文章变成好看的 HTML 页面、海报、卡片和 PNG。适合做杂志风文章、小红书卡片、知识卡片和分享图。
