# ChatCut 安装引导

ChatCut 是对话式 AI 视频编辑器（剪辑/字幕/转场/MG 动画/素材生成），经 Codex 插件接入。

## 做法

按官方引导安装——读教程页并照做（页面内含完整安装流程与环境要求）：

- 中文指令：`阅读 chatcut.io/chatgpt ，帮我安装 ChatCut 插件并创建一个新任务。`
- 英文指令：`Read chatcut.io/chatgpt to install the ChatCut plugin and set up a new task for me.`

官方教程：<https://chatcut.io/chatgpt>

注意：网页版会话无法安装（改不了桌面端本地插件目录），官方页会引导转桌面端执行。
