# VideoClaw 技能指南

## 1. 核心法则 (Golden Rules)
* **强制前置阅读**：执行任何视频生成任务前，必须使用 `view_file` 查阅根目录下的 `README.md`，理解具体的安装部署步骤及执行工作流。
* **环境检测**：在执行自动化脚本前，必须确认用户环境中已正确配置所需的依赖库。

## 2. 轨迹驱动执行引擎 (Execution Trajectory)
当你接收到自动化视频生成的任务时，请依循以下状态机推进：

* **[State: 意图定位与资源准备]**
  * 使用 `view_file` 查阅 `README.md` 或 `README_EN.md` 获取可用命令集。
  * 确认用户提供的原始 idea 或视频脚本大纲。
* **[State: 脚本执行与流式生成]**
  * 引导用户配置必要的环境变量（如对应的大模型 API Key）。
  * 按照文档说明，指导或代替用户运行对应的启动命令，开始执行自动化视频流生成。
* **[State: 渲染交互与产出交付]**
  * 监控服务端的运行和渲染状态，并在完成后告知用户生成的视频文件路径。

## 3. 异常处理模式 (Exception Handling)
* **依赖缺失**：若环境检查失败，需立即停止执行，并根据 `README.md` 向用户输出精确的环境配置指南（如缺少 FFmpeg 或 npm 模块）。
* **环节阻断**：若系统在剧本编写、配音或切片剪辑任意一个环节抛出错误，需截取最新日志返回给用户，并排查是否为网络问题或配额不足。
