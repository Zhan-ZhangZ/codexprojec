# KrillinAI 技能指南

## 1. 核心法则 (Golden Rules)
* **强制前置阅读**：执行任何视频翻译与配音任务前，必须使用 `view_file` 查阅根目录下的 `README.md`，理解具体的安装部署步骤及执行工作流。
* **环境检测**：在执行自动化脚本前，必须确认用户环境中已正确配置所需的依赖库（特别是 FFmpeg 与 Python 依赖）。

## 2. 轨迹驱动执行引擎 (Execution Trajectory)
当你接收到自动化视频翻译/配音的任务时，请依循以下状态机推进：

* **[State: 意图定位与资源准备]**
  * 使用 `view_file` 查阅 `README.md` 获取可用命令集和参数说明。
  * 确认用户提供的目标视频链接、目标语言、以及是否需要克隆原声等需求。
* **[State: 脚本执行与流式生成]**
  * 引导用户配置必要的环境变量（如大模型翻译 API、TTS 服务凭据等）。
  * 按照文档说明，指导或代替用户运行对应的启动命令，开始执行自动化视频处理流。
* **[State: 渲染交互与产出交付]**
  * 监控服务端的运行和渲染状态，并在完成后告知用户生成的带配音视频文件路径。

## 3. 异常处理模式 (Exception Handling)
* **依赖缺失**：若环境检查失败，需立即停止执行，并根据 `README.md` 向用户输出精确的环境配置指南（如缺少 FFmpeg 等）。
* **网络或配额阻断**：若系统在视频下载、语音识别或翻译配音任意一个环节抛出错误，需截取最新日志返回给用户，并排查是否为代理网络问题或 API 配额不足。
