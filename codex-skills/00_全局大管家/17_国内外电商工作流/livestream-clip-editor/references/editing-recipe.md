# 直播切片「精华拼接 + 逼单收尾」剪辑配方

把一段冗长的直播录屏，剪成约 1 分钟、节奏明快、以逼单（下单催促）收尾的带货短视频。
核心手法 = **切片拼接（jump-cut stitching）**：只保留口播精华句与钩子，句与句之间硬切去掉气口/废话，
整体提速，结构为 **钩子 → 卖点精华 → 逼单收尾**。不加字幕、不加 BGM（保留原声与原画面）。

---

## 0. 先确认需求（必问，避免返工）

- 目标时长（默认 ~60s，可接受 55–75s）。
- 是否提速、提多少（默认 1.25x；范围 1.2–1.3x）。
- 是否要字幕 / BGM（本配方默认**都不加**；参考片里若有字幕是原素材自带的烧录字幕，不是后期加的）。
- 收尾必须是**逼单**（尺码怎么拍、几号链接、上车、库存/价格催促），且最后一帧最好是主播站姿正对镜头/指镜头/举产品的强 CTA 画面。
- 输出目录与文件名。

## 1. 勘察原片与参考片（probe + 联系表）

```
python scripts/probe_media.py <原片.mp4>
python scripts/probe_media.py <参考成品.mp4>     # 若有参考片，反推它的剪辑参数
python scripts/contact_sheet.py <原片.mp4> sheet.jpg --interval 10
python scripts/contact_sheet.py <参考成品.mp4> ref_sheet.jpg --interval 5
```

- `probe_media.py` 输出：时长、编码/分辨率/帧率、`pauses`（静音气口，含 mid 中点）、`speech_ratio`（说话占比）、`jump_cuts`（场景切换点）、输入响度。
- 用 Read 工具看 `sheet.jpg`，把「时间 → 画面/动作/单品」对应起来，标记哪些段落是钩子、卖点、逼单、以及主播姿态好的画面。
- **反推参考片**：看它的 `speech_ratio`（本案例 ≈0.98，几乎无废话）、`jump_cuts` 间隔（≈5–14s 一切）、ASR 字数/说话秒数（≈7.15 字/秒）→ 推断提速倍率约 1.2–1.3x。

## 2. 中文 ASR 转写（拿到句级时间戳）

```
python scripts/transcribe.py <原片.mp4> transcript --model small --outdir .
```

- 产出 `transcript.json`（`[{start,end,text}]`）与 `transcript.txt`（带时间戳，便于人读）。
- 默认 `small` 模型、CPU int8、beam_size=1、cpu_threads=8（速度与质量平衡；medium+beam5+32线程在纯 CPU 上反而更慢且可能卡死）。
- 脚本已内置 Windows/中国网络修复（见 `windows-cn-pitfalls.md`）。
- 打印 `rate=X 字/秒`：原片正常语速约 5–6 字/秒；若参考片 ≈7.15，则提速 ≈7.15/原片rate。

## 3. 选句、排结构、写 EDL（最关键的人工判断）

读 `transcript.txt`，按结构挑选**完整句子块**（以句级时间戳为界，不要切在半句中间）：

1. **钩子（开头 0–10s）**：抓人的开场——痛点/反差/利益点（如「不高不瘦也能穿出型格」「跟对品牌」）。
2. **卖点精华（中段）**：版型显瘦、面料显贵、百搭、主理人背书、遮肉提拉等，每个卖点取 1–2 句最有力的。
3. **逼单（结尾）**：尺码怎么拍（按腰围体重/正码正拍/有肉往大拍）、价格/库存催促、几号链接、「上车」。
4. **收尾画面**：把主播**站姿正对镜头/指镜头/举产品**的那一句放到 EDL 最后（即使它在原片时间上不是最后），保证最后一帧是强 CTA。

EDL = 有序的 `[start, end]` 原片秒数列表，存成 `edl.json`：

```json
[[0.0,11.12],[14.49,17.35],[17.96,25.92], ... ,[315.71,320.51]]
```

也支持 `{"edl":[...],"speed":1.25}` 对象形式（render 会读取其中的 speed）。

选句原则：
- 块与块之间**硬切**即可，不用转场——拼接感正是参考片的风格。
- 去掉所有「嗯/啊/那个/重复/跑题/与单品无关」的段落。
- 控制总原始时长 ≈ 目标时长 × 提速倍率（如 60s × 1.25 ≈ 75s 原始素材；本案例取 83.6s → 66.9s）。
- 句子内部若仍有明显气口，可再细分成两块；但优先保证语义完整。

## 4. 渲染（拼接 + 提速 + 响度 + 限幅 + 淡入淡出）

```
python scripts/render_edit.py --src <原片.mp4> --edl edl.json --out 成品.mp4 --speed 1.25 --crf 19
```

filter_complex 链路（脚本已实现，无需手写）：
- 每块 `[0:v]trim=start=S:end=E,setpts=PTS-STARTPTS[vN]` + `[0:a]atrim=...,asetpts=PTS-STARTPTS[aN]`。
- `concat=n=N:v=1:a=1` 硬拼所有块（去气口）。
- 视频 `setpts=PTS/1.25`（提速），音频 `atempo=1.25`（提速且**不变调**）。
- 音频 `loudnorm=I=-16:TP=-2.0:LRA=11` 归一响度，再 `alimiter=limit=0.891:level=false` 防削波（实测 max≈-1.7dB）。
- 边缘淡入淡出：视频 in 0.2s / out 0.3s，音频 in 0.15s / out 0.25s。
- 编码 `libx264 preset medium crf19 profile high` + `aac 128k 44100` + `+faststart`（移动端秒开）。
- **不加字幕、不加 BGM**。

## 5. 校验（必做，PASS 才交付）

```
python scripts/verify_output.py 成品.mp4 --target-min 55 --target-max 75 --sheet fin_sheet.jpg --sheet-interval 6
```

自动检查：时长在目标区间、h264、yuv420p、有音轨、无黑帧、音频不削波（max ≤ -0.5dB）。
再用 Read 看 `fin_sheet.jpg`，**确认最后一帧是预期的逼单强 CTA 画面**（不是低头/弯腰/戴帽等弱画面）。
若收尾画面弱：回到第 3 步，把站姿指镜头的块挪到 EDL 末尾，重渲染。

## 6. 交付

把成品 mp4 放到用户指定目录；如用户需要，附 `edl.json`、`transcript.txt`、联系表与一句话清单。
本案例成品：`成品_精华拼接_逼单收尾.mp4`，67.0s，544×960，h264/aac，mean -16.7dB / max -1.7dB，无黑帧，逼单站姿收尾。
