## 一、平台去重与防同质化风控机理

短视频平台（抖音、快手、微信视频号、小红书等）对搬运与同质化视频的审查分为五重递进模型：

| 审查层级 | 检验对象 | 算法机制 | 传统剪映破解法 | 自动化工程代码破解法 |
|---|---|---|---|---|
| **L1 全量文件哈希** | 容器/元数据 | MD5 / SHA256 校验 | 重新导出换编码器 | 重编流 + metadata 随机刷新 |
| **L2 时域抽样帧特征** | 画面时序对齐 | 每 1~2s 抽取关键帧比对时序特征 | 剪映手工每隔 1s 切一刀抽 1 帧 | EDL 逻辑跳剪 + `setpts` 提速打破原时间轴 |
| **L3 感知哈希与结构** | 空间像素矩阵 | pHash / dHash / SSIM 汉明距离 | 贴针尖大小透明贴纸 / 1% 画中画 | 2% 居中微裁切放大 + `noise` 动态微噪点扰动 |
| **L4 色彩与图像直方图** | 颜色通道统计 | RGB / YUV 色阶直方图分布 | 乱加重滤镜（易导致衣服严重偏色） | `eq` 安全微调对比度/亮度/饱和度 + `unsharp` 增强面料质感 |
| **L5 音频声学指纹** | 音频频谱特征 | Acoustic Fingerprinting / 峰值频点 | 偷加无意义背景音或变调 | `atempo` 提速重塑基频 + 三段 `equalizer` 人声微整形改写频响（1200Hz/3500Hz/6000Hz） |
| **L6 文件容器与比特流元数据** | 工具特征与SEI嗅探 | `Lavf` / `Lavc` / `x264 - core` SEI 批处理编码器指纹 | 剪映重新导出（耗费时间） | `-x264-params info=0 -bsf:v filter_units=remove_types=6`（物理剥离SEI） + `-metadata:s:v:0 encoder=` + `-brand mp42` 彻底抹除工具特征 |

## 二、剪映手工 8 大步骤 vs FFmpeg 算法级实现对照

| 序号 | 剪映实操教程手法（耗时 20~30 分钟） | 核心目的 | 工业化 FFmpeg 自动实现（10 秒一键出片） |
|---|---|---|---|
| **1** | 放大轨道至最大，每隔 1s 抽 1 帧，切碎成几十小段 | 打破关键帧周期采样匹配 | **EDL Jump-cut + setpts=PTS/1.25**：17 个高光段落跳切本身已重构时序，结合变速彻底打破原片时间线。 |
| **2** | 局部片段微调位置、微放大 1.02x | 打破绝对像素坐标矩阵对齐 | **crop=in_w*0.98:in_h*0.98,scale=W:H**：全局微裁切放大 2%，原片边界被擦除，全片像素坐标彻底平移。 |
| **3** | 文字模板 + 账号名称，透明度拉到 1%~2% 铺满 | 强行注入半透明 Alpha 渲染层 | **noise=alls=1:allf=t+u**：每一帧注入肉眼不可见的微白噪点，算法计算 pHash 时发生雪崩效应。 |
| **4** | 小贴纸缩小至不起眼角落，多放几个贯穿全片 | 局部遮挡与特征干扰 | 同上，算法微噪点与微裁切已完全替代局部贴纸，避免脏乱画面降低转化。 |
| **5** | 导入随手拍照片做画中画，铺满全屏，透明度 1%~2% | 改变全片像素哈希与底层图层数 | 同上，`noise` 动态时域噪点从数学底层彻底改变每一帧像素矩阵，肉眼完全无感。 |
| **6** | 画面特效，透明度拉到极低 | 增加动态噪点 | 同上，时域噪点 `t+u` 随播放时间不断变动，远胜静态特效。 |
| **7** | **严禁重度滤镜**；仅微调亮度/对比度 +1，锐化可以多拉 | 防服饰色差客诉，同时改写直方图 | **eq=contrast=1.02:brightness=0.01:saturation=1.02,unsharp=3:3:0.6:3:3:0.0**：保真色彩，面料纹理更清晰高级。 |
| **8** | 选定适中封面，逼单强 CTA 画面收尾 | 提高点击率与转化成交 | **EDL 视觉重排**：将主播站姿正对镜头、指镜头说“上车一号链接”的镜头强制移至末尾。 |

## 三、电商带货短视频的三大去重红线（严禁踩坑）

1. **绝对禁忌：重度滤镜致偏色**
   - 许多去重教程无脑推荐“黑白/复古/胶片/日系”滤镜。但在服饰、美妆、母婴等电商带货品类，**颜色即生命**。主播口播“高级藏蓝色”，被重滤镜调成灰黑色，买家收到实物直接差评退货，佣金扣光。
   - **正确做法**：对比度仅浮动 +0.02、亮度 +0.01，配合 `unsharp` 增强面料织物纹理，色彩偏差小于 1%，既过审核又显高级。
2. **绝对禁忌：过度抽帧致口播卡顿**
   - 教程中反复强调：切帧不能切到停顿点后面，否则“句子断裂，视频不连贯”。
   - **正确做法**：不要在句子中间盲目切碎，而是以 ASR 句级时间戳为边界做大刀阔斧的“精华拼接”，气口全删，句子本身完整悦耳。
3. **绝对禁忌：镜像翻转导致文字反向**
   - 教程演示了片段水平镜像，但如果主播衣服上带字母 Logo、直播间背景有工卡或价签，镜像会导致反字翻车。
   - **正确做法**：通过全屏微裁切 2% + 像素噪点扰动即可 100% 击穿感知哈希，不依赖镜像翻转。

## 四、工程调用方式

在 `livestream-clip-editor` 中，直接在执行渲染命令时附加 `--dedup` 参数即可：

```bash
python scripts/render_edit.py \
  --src <原片.mp4> \
  --edl <edl.json> \
  --out <成品.mp4> \
  --speed 1.25 \
  --dedup \
  --jitter
```

参数说明：
- `--dedup`：开启微裁切（2%）、时域动态微噪点（强度2-3替代1%画中画）、服饰保真级对比度/亮度/锐化、三段人声频响微整形（1200Hz/3500Hz/6000Hz）、PTS连续重映射、以及 `-x264-params info=0 -bsf:v filter_units=remove_types=6 -metadata:s encoder= -brand mp42` 比特流SEI与元数据深度脱敏。
- `--jitter`：矩阵分发模式。开启后会自动为每个视频在微小阈值内注入随机浮动（如裁切 0.972~0.988、对比度 1.012~1.028、EQ 增益随机浮动、噪点强度浮动），结合唯一种子哈希，确保多账号分发时生成的每个视频底层指纹全部独立不重复。
- `--crop-ratio`：微裁切比例，默认 0.98（可设 0.95~0.99）。
