# Ozon 官方教育内容蒸馏：运营诊断方法

> 调研日期：2026-07-22（Asia/Shanghai）  
> 范围：仅使用 Ozon / Ozon Global 官方帮助中心、官方卖家媒体「Бестселлер」和官方 Ozon Marketplace 频道。  
> 用途：为公开版 `ozon-university` 提供“官方怎么教卖家定位问题”的证据层；不是内部 SOP，也不包含第三方 KOL 观点。  
> 时效提醒：Ozon 帮助中心是持续更新的活文档。页面未展示发布日期时，下文标记为“无页面日期”；数字阈值、功能可用性和后台路径在回答用户前应再次核对。

## 一、最值得写进 Skill 的官方诊断骨架

Ozon 官方并没有在单页给出一句完整的“曝光—点击—转化诊断公式”，但其「图表」预设指标组已经构成一条明确漏斗：

`搜索/目录展示 → 商品卡展示/访问 → 加购 → 下单 → 销售额 → 取消/退货`

官方建议先看各阶段的转化比例，找出最低的阶段转换，再对相应环节采取动作，而不是一上来就加广告或降价。可落成以下工作流：

1. 在「分析 → 图表」选“销售漏斗”，定位流失最大的相邻阶段。
2. 若搜索/目录没有展示，先检查是否被索引、是否有库存、卡片是否有错误/违规，再按查询词和买家地区检查真实搜索位置。
3. 若展示不足但卡片点击和加购转化已经较好，官方预设组“需要推广”建议给这类商品增加推广，让更多潜在买家看到它。
4. 若搜索位置高但销量低，官方建议先改善商品卡和商品质量；若商品卡访问后的加购转化低，也先改善卡片。
5. 单独检查价格指数、配送速度/地区库存、评价、查询相关性，以及推广数据中的 CTR、加购转化、每单成本和广告费用占销售额比例。
6. 每次只针对瓶颈做调整，然后使用相同商品、地区、时间粒度比较前后数据；搜索排名是实时、个性化和相对竞争的，不能把两个时点的绝对分数机械相加或直接比较。

**证据强度：高。** 第 1、3、4 步为官方帮助中心明确建议；第 2、5 步为多个官方工具说明的组合；“每次只针对瓶颈做调整”是基于官方漏斗和指标比较功能整理出的工作方法，不是 Ozon 原文中的强制规则。

## 二、按症状拆解的官方方法

### 1. 没曝光 / 曝光下降

先区分“根本没进入搜索”和“进入搜索但排名低”。

- 用「商品在搜索结果中的位置」按**查询词 + 买家城市/地区 + 商品**检查。官方明确说搜索位置会随地区、设备和其他因素变化。
- 若显示“未进入搜索索引”，官方列出的首要原因包括：超过 30 天无库存、商品卡有错误、商品因违规被屏蔽。先补库存、修卡片错误或处理屏蔽，不要先投广告。
- 若已被索引但位置低，用「什么影响搜索位置」把自己的商品钉住并与竞争商品比较；优先看权重最高的参数，不要把不同参数的分数简单相加。
- 该官方页面当前列出的基础因素包括：按查询词的受欢迎程度 29%、近 60 天商品销量 17%、查询相关性 12%、整体受欢迎程度 10%、评价 5%、价格 5%、配送 3%。此外还有价格指数和促销/快速配送等提升系数。**这些权重高度动态，只能作为页面当前快照，不能写成永久算法。**
- 查询相关性来自标题、描述和其他字段与搜索词的匹配；官方「我的商品查询」示例建议：若买家常用“木梳”购买，而标题仅写“按摩梳”，应在属性中补充材质并在描述中展开。
- 官方提醒：搜索每次都会重新计算，且竞争商品也会变化，因此编辑卡片后绝对分数下降不等于优化无效。

### 2. 曝光高，但点击/进卡少

**已找到的官方事实：** 推广分析定义 CTR 为点击数 ÷ 展示数，可按商品/类目/期间查看 CTR、展示和点击变化；商品在搜索结果及卡片前部会显示主图、附图/视频、名称、价格、配送、评分/评价、促销标记等信息。

**官方未找到：** 在本轮可公开访问的官方材料中，没有找到一份明确写成“曝光高、CTR 低时，按主图 → 标题 → 价格 → 配送逐项排查”的官方诊断清单，也没有找到适用于所有类目的官方 CTR 合格线。

因此 Skill 应这样回答：

- 先报告 CTR 及其变化，并与同一商品历史、同类商品或不同查询词比较。
- 可提示检查搜索结果页可见的主图、名称、价格、评分与配送，但必须标为“基于官方展示结构的诊断推断”，不要伪装成 Ozon 官方固定顺序。
- 不要给出来源不明的“CTR 达到 X% 才合格”。

### 3. 进卡多，但加购/下单转化低

- 官方「图表」说明：若商品卡访问后的加购转化低，应改进商品卡以吸引买家。
- Ozon 官方频道在 2026-02-10 公布了新版内容评级：媒体 45 分、描述 25 分、属性 30 分；至少 8 张图片并加入商品视频带来最大的卡片到购买转化提升，100–500 字符的简洁说明销售表现更好，属性填写达到 70% 及以上可得该项最高分。
- 官方同时明确：此次内容评级重算**不影响搜索位置**。因此不能把“内容评级 100 分”表述成直接的搜索排名因子；它更适合用于转化诊断。
- 官方高质量商品卡示例的共性：标题包含买家识别商品所需的关键字段；图片/视频清晰展示整体、细节、材质、尺寸、颜色、使用效果或配件；描述不冗长但解释特点和优势；填写筛选器所需属性和附加属性。
- 最新内容评级的操作顺序是：筛出低于 100 分的商品 → 打开评分详情 → 按后台给出的影响优先级补内容 → 所有标签出现绿勾后达到 100 分。此顺序比第三方“万能图片模板”更可信。

### 4. 价格是否有问题

- 「搜索查询」提供查询热度、加购人数、加购转化和平均加购金额。官方建议：若某查询的平均加购金额显著高于或低于你的售价，应调整价格，或分析该查询下不同价格带商品的差异。
- 价格指数比较你的 Ozon 售价与 Ozon 站内竞争者和其他网站的可见价格，当前分为有利、中等、不利。
- 当前帮助页给出的指数色级快照：绿色不高于 1.02，黄色 1.02–1.05，红色 1.06 及以上；若缺乏可比链接/数据则可能不计算指数。
- 当前帮助页称：有利价格指数商品相对不利指数商品获得 7.5% 的额外搜索推广，中等指数为 5%；不利指数本身没有处罚或屏蔽，只是拿不到额外推广。
- 官方改善建议：复核中等/不利商品的价格；可用自动定价策略保持竞争力；必要时补充其他网站的同款链接以改善比较数据。
- 价格判断必须结合利润，不应因为指数不利就机械降价。后半句是风险控制原则，并非 Ozon 官方在上述页面给出的完整利润 SOP。

### 5. 物流、库存和地区问题

- 搜索因素页当前将配送速度列为基础权重 3%，并列出快速配送提升系数；该页说明配送越快得分越高。
- 官方类目研究明确建议把库存送往 Ozon 各集群，因为配送时效强烈影响客户选择；其季节案例中，1–2 天配送帮助订单增长维持到更晚日期。
- 「分析工具」中的集群分析可查看商品在集群间的流动和物流费用，用来决定向哪些集群补货并降低费用。
- 没有库存超过 30 天可能导致商品不进入搜索索引。
- realFBS 的“按时交货”指标按最近 7 天计算；官方建议不低于 80%，改善方式是及时交付新订单或选择可靠物流商。该指标与“搜索转化”不是同一个概念，回答时不要混淆。

### 6. 广告怎么诊断，而不是只看花费

- 官方推广分析要求同时看：推广带来的订单/销售、每单或每次点击成本、CTR、展示、点击、订单、不同推广工具贡献、推广费用及其占总销售额的比例。
- 加购转化定义为推广商品加购数 ÷ 点击数；每单成本 = 推广费用 ÷ 订单数；每次点击成本 = 推广费用 ÷ 点击数。
- 官方「图表」中的“需要推广”预设组，推荐先找**卡片点击和加购转化已经较高、但曝光不足**的商品，再增加推广。这是非常重要的“先验证承接，再放大流量”启发式。
- 若商品搜索位置高但销量低，官方建议改善卡片和商品质量；这意味着“排名高但不卖”不应先用更高竞价解决。
- 当前“付费搜索结果推广”页面说明，系统会给出竞争费率和有/无当前费率的预计曝光，可逐步改变费率寻找合适值；估算会受竞争者出价、商品评分、价格等因素影响，只是近似值。
- 当前页面还建议广告之外同步做：补视频和卡片信息、积累评价、让价格贴近市场、参加促销或给买家特别优惠。
- 广告归因口径、收费模式、最低费率、可推广资格和功能名称经常变化，Skill 不应固化金额或默认所有跨境卖家都能使用同一工具。

## 三、事实、官方启发式与我们的整理

| 类型 | 可以直接说什么 | 回答时的标签 |
|---|---|---|
| 平台事实 | 指标定义、后台路径、当前搜索因素与权重、价格指数算法、内容评级公式、资格限制 | `官方规则/当前产品说明` |
| 官方启发式 | 漏斗找最低转化；高点击/高加购但低曝光的商品适合放大推广；高排名低销量先改卡片/质量；按后台内容评级优先级补内容 | `Ozon 官方建议` |
| 本研究整理 | 把多个页面合并成“索引 → 排名 → CTR → 加购 → 订单 → 售后”的排查树；建议一次只处理一个瓶颈 | `基于官方资料整理` |
| 不可冒充官方 | “主图必须放 X 个卖点”“CTR 低于 X% 就失败”“内容评级直接提高自然排名”“只要提价/降价就能修复转化” | `未获官方证实` |

## 六、给主 Skill 的引用规则

1. 回答“平台现在如何计算/限制”时，优先引用帮助中心，并注明“截至资料检索日”。
2. 回答“我该先做什么”时，可引用官方预设分析法，但要把组合后的排查顺序标为“基于官方资料整理”。
3. 涉及搜索权重、价格指数阈值、广告资格/费率、物流服务时，提示用户打开来源页核对当前账号与国家。
4. 任何没有来源的经验阈值都不能写成 Ozon 官方结论；应转入 KOL/经验层并说明适用范围。
