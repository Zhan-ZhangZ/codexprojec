# Ozon University Skill

一个面向 Ozon 新手卖家和运营实习生的公开问答导航 Skill。它把“我现在该查什么”转成有顺序的检查清单，并区分 Ozon 官方规则、公开实践者经验和待验证推断。

> 本目录是 codex-skills 集成版。技能入口为本目录根部的 `SKILL.md`，参考资料按需从 `references/` 加载。

## 能回答什么

- 商品发布、审核、索引和内容质量；
- 曝光、点击、加购、下单等漏斗诊断；
- 定价、成本字段和利润核算思路；
- 广告投放前置条件与异常排查；
- 物流履约、取消、退货和争议处理；
- 铺货、精品等公开运营流派的适用边界；
- 某条“最新规则”应该到哪里核验。

它不会登录或操作店铺，不提供内部经营数据，也不会在缺乏官方证据时编造精确费率和平台规则。

## 安装与使用

将本目录整体放入客户端可发现的 Skills 目录。Codex 用户可以将它放在：

```text
~/.codex/skills/ozon-university/
```

安装后在新任务中直接提出 Ozon 运营问题，也可以显式调用 `$ozon-university`。WorkBuddy 的 Skill 结构和导入方式见[官方说明](https://cloud.tencent.com/document/product/1831/134516)。

## 示例

```text
我的商品已经上架三天，一点曝光都没有，先查什么？

曝光不少但点击很低，是不是应该马上降价？

两个博主一个建议铺货，一个建议精品，我该怎么判断？

有人说 Ozon 最近修改了佣金，这是真的吗？
```

## 目录结构

```text
ozon-university/
├── SKILL.md
├── README.md
├── LICENSE
├── agents/openai.yaml
└── references/
    ├── *.md
    └── research/*.md
```

`SKILL.md` 是运行入口；`references/` 保存按领域拆分的运营资料和公开来源研究。上游用于 CI、测试和发布打包的目录未纳入发布技能。

## 来源原则

优先采用 Ozon 官方 Seller 文档、官方公告和官方培训；公开实践者内容只作为情境经验，并保留分歧。涉及费率、类目限制、物流和广告规则等易变化信息时，应重新核验官方页面。
