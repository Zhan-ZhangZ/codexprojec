# ecom-details-image

面向 claude code / Codex / OpenClaw 的跨境电商和国内电商通用视觉创作 Skill。生成电商主图、详情页图片、社媒推广图、直播间场景图等全套视觉素材。支持 Campaign Style Lock 机制，保证整套图视觉一致。

## 何时使用

适用任务：面向 claude code / Codex / OpenClaw 的跨境电商和国内电商通用视觉创作 Skill。生成电商主图、详情页图片、社媒推广图、直播间场景图等全套视觉素材。支持 Campaign Style Lock 机制，保证整套图视觉一致。

## 执行

1. 读取 `README.md` 的产品定位和素材要求。
2. 按 `.claude/skills/ecom-details-image/SKILL.md` 执行主图、详情页、推广图或场景图工作流，并遵守其中的 Campaign Style Lock。
3. 生图前确认商品主体、品牌信息、尺寸、目标市场与平台规范；输出时区分视觉概念、提示词和实际生成的文件。
