# Anthropic Official Skills

- **项目主页**: https://github.com/anthropics/skills

## 功能说明
Anthropic 官方示例技能库（19 个成员技能）。主要用来学习"一个好 Skill 应该怎么写"，也适合拿来当模板，改成自己的专属技能；`skills/claude-api` 覆盖 10+ 语言的官方 SDK 用法与 Managed Agents 服务端代理。

## 详细指南
请参考本地代码库中的 [README.md](./README.md) 获取详细使用说明与模版。

## 成员速览（2026-09-01 上游快照）

| 成员 | 用途 |
|---|---|
| `claude-api` | Claude API 官方用法大全（10+ 语言 SDK / curl / Managed Agents / 批处理 / 流式） |
| `mcp-builder` | MCP 服务构建指南（本库已单列） |
| `skill-creator` | 技能创建与迭代改进（本库已单列） |
| `academy-guide` | Claude 学习路径导引（2026-08 新增） |
| `web-artifacts-builder` / `frontend-design` / `canvas-design` | 前端与视觉构建 |
| `algorithmic-art` / `brand-guidelines` / `discernment-nudge` | 算法艺术、品牌规范、判断力护栏 |
| `docx` / `pdf` / `pptx` / `xlsx` / `doc-coauthoring` | Office 文档四件套与共笔 |
| `internal-comms` / `theme-factory` / `webapp-testing` | 文档、主题、Web 测试 |

> 成员技能如需独立使用，本库多数已按类目单列（见索引表）；此处保留整仓结构供模板研读。
