# 安全策略

## 支持范围

安全修复面向最新开发分支和最近一个正式版本。

## 报告漏洞

请勿为安全漏洞创建公开 GitHub Issue。请优先使用本仓库的 GitHub Security Advisory 私下报告；若该功能暂不可用，请等待维护者启用安全报告渠道。

报告中请包含：

- 问题描述与影响范围
- 可复现步骤或最小证明
- 受影响的工作流
- 可选的缓解或修复建议

目标是在 7 天内确认收到，并在确认问题后 30 天内提供修复或缓解方案。

## 本地数据与凭据

- 应用以本地优先方式运行，数据库默认位于 `~/.skillsmanage/db.sqlite`。
- GitHub PAT、X Bearer Token 和可选 AI 服务密钥保存在本地数据库中，目前不会由应用额外加密。
- 请使用最小权限令牌，并保护操作系统账户。
- 应用不包含分析、崩溃上报或使用跟踪。
- 只有在用户主动使用市场刷新、仓库导入、更新检查等联网功能时才发起网络请求。
- 当前版本不会执行从技能仓库发现的未验证脚本或 Hooks。

## 安全安装与卸载

- Windows 无法创建软链接时必须由用户明确确认后才能改用复制。
- 复制安装会记录内容哈希和同步状态。
- 只有应用自身记录为“受管理”的项目技能才允许卸载。
- 同名但内容不同的目录不会被静默覆盖。

## 公开内容脱敏

提交 Issue、日志或 Pull Request 前必须移除 API Key、访问令牌、密码、私钥、JWT、私人目录和个人身份信息。请使用 `<已脱敏>` 等占位符。
