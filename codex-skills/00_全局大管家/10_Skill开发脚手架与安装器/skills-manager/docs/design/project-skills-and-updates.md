# 项目技能、分类与更新设计

本文档是 0.10.0 阶段的历史设计入口。原方案已经完成中文整理，并在 0.11.0 中扩展了独立项目管理、技能包、跨平台适配和趋势市场。

当前有效设计请阅读：

- [项目技能管理与技能包重构](项目技能管理与技能包重构.md)
- [0.11.0 数据迁移说明](../migrations/0.11.0-数据迁移说明.md)
- [0.11.0 测试验证记录](../testing/0.11.0-测试验证记录.md)

历史方案中的核心原则继续保留：

1. 项目注册与技能扫描是两个独立概念。
2. 中央技能库是安装来源，项目目录是部署目标。
3. 同内容去重，同名异内容必须显式处理冲突。
4. 只允许卸载由本应用记录和管理的链接或副本。
5. 分类结果可人工覆盖，更新检查与实际更新分离。
6. Windows 软链接失败不得静默复制。
