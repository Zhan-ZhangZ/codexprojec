## 新增重点用例

- 任意普通目录可注册为项目，不要求 Git 或已有 Skills。
- 项目路径去重，移除项目不会删除项目文件。
- 同内容安装去重，同名异内容报告冲突。
- 只允许卸载由应用管理的链接或副本。
- 受管理副本同步时会安全替换平台适配目录。
- 技能包仓库快照哈希不受 `HashMap` 顺序影响。
- 带 Hooks 的技能包平台清单会标记为高风险且不自动执行。
- 趋势市场有历史基线时计算真实增量，冷启动时明确标记估算。
- 中央技能卡片可直接打开项目安装弹窗。
- 项目页展示空项目、普通目录、受管理副本同步与卸载入口。
- 项目页安装入口默认展示中央技能库，支持多选批量安装，并可切换到技能集合或外部导入。
- 项目页不再提供从技能市场直接安装到项目的跳转。
- 项目安装弹窗受视口宽高约束，长技能描述不会横向撑开弹窗，技能列表独立滚动且底部安装按钮始终可见。
- 中央技能平台摘要会排除已停用的历史平台。
- 中央技能可按不同本地项目的使用次数排序，同一项目的重复适配路径不会重复计数。
