# 更新日志

本项目统一使用中文维护文档。完整历史记录见 [CHANGELOG.zh.md](CHANGELOG.zh.md)。

## 0.11.0 - 2026-07-26

### 新功能

- 新增独立“项目”页面，可手动添加任意本地目录。
- 新增项目级技能安装、批量安装、受管理卸载和副本同步。
- 新增中央技能分类、标签、更新状态筛选与批量更新。
- 新增多技能仓库“技能包”模型，保留完整仓库快照和子技能关系。
- 新增 GitHub、X、Hugging Face 趋势技能市场数据源。
- 新增本地平台检测优先排序，Codex 固定首位。

### 修复

- 修复中央技能库“安装到项目”入口不可用的问题。
- 项目注册与设置中的技能扫描目录彻底解耦。
- Windows 软链接失败时改为显式请求复制确认，不再静默降级。
- 消除前端不同页面之间的平台静态名单漂移。

### 文档与验证

- 项目维护文档统一为中文。
- 新增 0.11.0 设计、迁移和测试验证记录。
