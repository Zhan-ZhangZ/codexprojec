# skills-manage 0.9.1

这是一次小型维护版本，重点修正跨平台场景下的完整路径显示。

## 亮点

- 中央技能库、平台页、设置页、全局搜索与平台编辑流程统一显示完整绝对路径。
- Windows 路径统一使用带盘符的反斜杠格式。
- 自定义平台的默认目录会匹配当前系统的主目录风格。
- 补充路径展示规则的自动化测试。
