# skills-manage 0.8.0

`skills-manage` 的首个公开发布版本。

## 亮点

- 统一管理内置和自定义 AI Agent 平台的 Skills。
- 提供中央技能库、平台安装、技能集合和详情预览。
- 提供项目技能发现扫描。
- 提供技能市场、AI 技能解释和 GitHub 仓库导入。
- 提供命令面板、双语界面和 Catppuccin 主题。
- 优化中央库、项目发现和全局搜索的大列表性能。
