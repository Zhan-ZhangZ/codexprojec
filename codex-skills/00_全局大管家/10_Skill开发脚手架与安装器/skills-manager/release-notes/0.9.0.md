# skills-manage 0.9.0

本版本重点增强 Windows、macOS Universal 打包，以及安装、重扫和多来源详情链路的稳定性。

## 亮点

- 新增 Windows x64 的 MSI 与便携 ZIP 包。
- macOS 升级为 Universal DMG、ZIP 与 TAR.GZ。
- 改进跨平台路径处理和安装可靠性。
- 修复 Claude 多来源技能在平台行、详情与解释页面之间的连续性。
- 修复全量重扫后的状态刷新传播。

## 安装包

- `skills-manage_0.9.0_windows_x64.msi`
- `skills-manage_0.9.0_windows_x64.zip`
- `skills-manage_0.9.0_macos_universal.dmg`
- `skills-manage_0.9.0_macos_universal.zip`
- `skills-manage_0.9.0_macos_universal.tar.gz`

该历史版本曾在 Windows 软链接失败时自动复制；从 0.11.0 起已改为要求用户明确确认。
